# 03 · Content Engine

One sentence in, finished scripts and edited reels out, on brand.

## Agents

- **Viral ad scriptwriter**: Turns one sentence into a set of ad scripts (hook, story, call to action)
- **AI edit crew (seven seats)**: Editor, transcriber, B-roll researcher, screen editor, sound designer, animator and finisher take raw footage to finished vertical and horizontal reels
- **Motion engineer**: Builds reusable animated reel templates and motion graphics

## Skills

- **Brand video engine**: Renders on-brand product and proof reels from real footage
- **Shot list director**: Plans shoots so every shot has a job in the edit
- **Agent-authored video**: Makes quick explainer and quote-card videos with no human editing
- **Social posting kit**: Prepares ready-to-post kits for channels that can't be automated
- **Slide and carousel generator**: Builds on-brand decks and LinkedIn carousels

## Loops

- **Creative library sync**: Pulls every ad from Google, Meta and Microsoft daily, then renders and describes each one so the library can be searched

## Automations

- **Content studio request desk**: One front door where staff request creative and track it

Architecture

One session, wrapped in enforcement, with memory underneath. The assistant never touches your real systems except through a gate.

The layers, outside in

You

You state a goal and read a result. You hold the keys: every approval that moves money, sends a message or changes a live platform is yours.

The enforcement band (31 hooks)

Hooks run on tool calls and turn endings. They are code, not instructions: a rule written only as prose can be talked around, a hook cannot. See every hook and why it exists.

Rules (18)

The doctrine in plain markdown: loud failure, execute now, plain English, data tiers, the opsec gate, the accuracy hierarchy, the ingress rule, consent evidence and more. A plugin cannot ship rules directly, so the install-rules skill copies them into your project.

Skills (49)

Methods you invoke by name: goal, grill, diagnose, distill, ingest, handoff, compliance audit and the rest.

Agents (26)

Specialist seats, each pinned to a model tier and an effort level, each with a stated way its work is checked. Builders build. Reviewers read and never edit. See every agent and the review loop.

System packs (8)

A pack ties a domain to its skills, agents, gates and memory. The goal skill reads the registry, picks the pack, and runs the work to the first protected gate.

The gates that ship empty

Three gates are installed but start with no rows, because only you know your platforms: the platform-write registry, the ingress registry and the api governor's vendor registry. Until you add a row they allow every write except minting an approval, and say so once. Add a row and the gate becomes real.

The vault

Plain markdown, an index that loads every session, templates, and tools to search, lint, rename and push it. See the vault method.

Optional services: configured, or one clear line

Nothing crashes when a piece is missing. Each hook that depends on something prints a single "not configured" line.

Data tiers and what may see them

The data-handling rule sorts everything into four tiers and says which AI tool may touch each. The short form: regulated and confidential data never enters a consumer chat window, and the on-device lane exists for work over raw records.

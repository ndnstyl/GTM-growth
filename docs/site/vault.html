The vault method

A folder of plain markdown that remembers what you decided, so the assistant does not ask you the same question twice and you never lose a hard-won rule to a closed session.

The layout

FolderHolds
00-BOARDthe status record: board, north star, queue, one card per piece of work
10-PROJECTSwork with an end
20-AREASresponsibilities that never end
30-KNOWLEDGEwhat you learned: concepts, references, people
40-SOPShow someone else runs it, in three parts: by hand, what the assistant does, what is being built
90-ARCHIVEretired notes
raw/sources exactly as they arrived, never edited
MEMORY.mdthe index: one line per note, small enough to load into every session

The contract that keeps it searchable

  • Every note has a description (one declarative sentence) and a type (feedback, project, reference, user, learning, source or sop).
  • Titles are sentences a person would say. A hard rule is a title that states the rule.
  • Every note is linked from the index or a folder map. A note nobody links to does not exist.
  • A fact that goes stale carries a refresh_due date.
  • A count carries how it was counted.

The loop

  1. Capture the moment. The distill skill pulls corrections, decisions and diagnosed bugs out of the conversation as they happen, not at the end of a long session.
  2. Keep the source. The raw excerpt goes in raw/; the note cites it. A note without provenance is an opinion.
  3. Recall before work. Hooks search the vault on each prompt and on each delegation, so a delegated agent starts with the rules you already ruled.
  4. Lint. A deterministic script checks the index size, broken links, orphans, frontmatter, duplicate names and stale dates. Zero broken and zero orphans is the bar.

The tools

Search (keyword ranking, with an optional reranker), lint, reachability, rename with link rewriting, frontmatter refactor, commit, push-and-verify to another machine, and index expiry. All in the plugin's scripts folder, all standard-library Python.

The example vault

The repository carries a fictional company, Harbor and Pine Home Services: about two dozen notes plus the index, log and schema, showing the method in motion. Follow one rule from its raw source to the note that states it to the card that records its effect. Every company, person and number in it is invented. It passes its own lint with zero warnings.

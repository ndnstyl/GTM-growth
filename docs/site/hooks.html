Hooks (31 registered)

Anything that must happen is a hook, not an instruction. A rule in a prose file can be talked around; a hook that exits non-zero cannot.

Each hook below names the failure it prevents. Hooks that depend on a service you have not configured print one "not configured" line instead of failing. Hooks that block do so with the rule quoted back, so the assistant learns why.

When a session starts

HookOnWhy it exists
startup-load.shallA session that starts with half its parts missing looks fine and then misbehaves. This prints one line at the start saying which optional pieces (vault, remote vault, local model) are configured, and loads your constitution.

When you send a prompt

HookOnWhy it exists
vault-recall-prompt.shallMemory that depends on the assistant remembering to look fails quietly. This searches your vault on every prompt and puts the best matches in front of the assistant before it answers.

Before a tool runs (can block)

HookOnWhy it exists
checkpoint-before-change.shWrite|Edit|BashA local change should never need a permission slog, but it should always be undoable. Before a file in a governed path is changed, the current bytes are copied aside so the change can be reverted.
block-duplicate-spec-number.shWrite|Edit|BashTwo spec folders with the same number make every reference ambiguous. This refuses the write that would create the second one.
block-local-zone-read.shRead|Grep|BashRaw sensitive files should be read only by a model on your own machine. This walls a local-only folder off from the cloud session; the sanctioned on-device path is exempt.
block-off-trunk-commit.shBashFinished work that lands on a stray branch is finished work nobody sees. This refuses a commit that is not on trunk or a spec branch. Set OPERATOR_TRUNK_BRANCH_RX to allow your own branch names, or OPERATOR_TRUNK_GRACE=1 for a one-time commit.
block-blind-grep.shBashIn some shells a recursive search silently skips ignored folders and reports zero hits, which reads as proof of absence. This blocks the blind search and points to one that sees everything.
block-detached-process.shBashA server an agent starts in the background and walks away from can run for days with no owner. This refuses detached launches unless they are marked and stopped.
block-local-path-disclosure.shBashA path on your machine means nothing to the reader and exposes how your machine is laid out. This refuses outbound text (mail drafts, posts, messages) that names one.
conflict-check.shWrite|EditTwo agents editing the same file at once overwrite each other. This checks declared file ownership before an edit.
block-sensitive-write.shWrite|EditA stray write to a credentials file or a key store is the quietest way to lock yourself out or leak a secret. This refuses writes to env files, key folders and similar paths.
block-silent-failure.shWrite|EditCode that swallows its own errors is how a job reports success while doing nothing. This refuses new swallowed exceptions, unchecked exit codes and hidden errors at write time and quotes the rule.
block-sensitive-mcp.shmcp__.*Some connected-tool calls cannot be undone: sending a message, editing a live workflow. This holds those until you approve.
governance-egress-guard.shmcp__.*|WebFetch|BashSecrets leak through outbound payloads. This inspects what is about to leave (web fetches, connected tools, shell) and warns loudly and logs it. It warns; it does not block.
vault-recall-inject.shAgentA delegated agent starts with none of your memory. This attaches the most relevant vault notes to every delegation so the agent does not rediscover a rule you already ruled.
block-destructive.shBashThe commands that cost the most are few and known: recursive deletes, history rewrites on a shared tree, secret exfiltration, mass database changes, pipe-to-shell. This blocks them.
platform-write-gate.shBash|mcp__.*An agent should prepare a change to your CRM, ad account or inbox, never apply it. This gates any call that writes outside your machine behind your approval. The registry ships empty; you add your platforms.
block-ingress-drift.shWrite|Edit|BashEvery new hostname, hosting project or tunnel is a future audit finding. This refuses a write that mints a public name you have not registered. The registry ships empty.
warehouse-first-gate.shBashA figure added up by hand in a terminal changes between runs. This stops ad hoc summing of governed datasets and points to the one query that defines the number. Off until you configure it.

After a tool runs

HookOnWhy it exists
auto-lint.shWrite|EditStyle drift is cheaper to fix the moment it happens. After a JavaScript or TypeScript edit it runs your linter.
type-check.shWrite|EditA type error found at edit time costs seconds; found at deploy it costs an afternoon. After an edit it type-checks the nearest project and reports without blocking.
memory-index-cap-guard.shWrite|EditThe vault index is loaded whole and truncated past a size cap, which fails silently. This warns the moment an edit pushes the index toward the cap.
audit-log.sh.*Autonomous work you cannot see is work you cannot trust. Every tool call is appended to a local record you can read later.
inject-untrusted-warning.shWebFetch|WebSearch|mcp__.*Web pages, emails and tool results can carry instructions aimed at the assistant. This marks external content as untrusted data, not as orders.

Before the context is compacted

HookOnWhy it exists
precompact-save.shallContext compaction forgets. Before it runs, a snapshot of the repository state is written so the thread can be picked up.

When a turn ends

HookOnWhy it exists
session-log.shallA record of each session, one file per session however many turns it took.
token-budget.shallA long task needs a spending ceiling stated up front. This tracks token use against the budget at the end of each turn.
scrub-secrets-on-stop.shallSession transcripts are a verbatim log, including anything secret that was printed. This finds live secrets in them and reports; with one setting it redacts them.
execute-now-stop-gate.shallA reply that ends 'want me to draft it?' hands the work back to you. This refuses to end a turn on an offer unless it names a real blocker that sits on you.
vault-push-on-stop.shallA note that exists on one machine only is one disk failure from gone. If you keep a canonical vault elsewhere, this pushes and verifies every vault write before the turn ends.

When a delegated agent finishes

HookOnWhy it exists
outcome-capture.shallWithout a record of how each delegated agent did, you cannot tune the seats. One outcome line is written per agent run.

Shipped but not registered

Opt in from your own settings.

HookWhy it is optional
unslop-stop-gate.shOptional. Refuses a final message that carries the most obvious machine-written tells. It costs a regenerated message per block, so it ships unregistered.
name-the-thing-stop-gate.shOptional. Refuses a final message that points at work by ticket, task or phase number instead of saying what the thing is. Ships unregistered.
pre-commit-secret-scan.shOptional git hook. Blocks a commit that contains a secret pattern, using the same pattern list as the egress guard.

Tutorial 1 of 4 · Two minutes

Install in two minutes

By the end you have Operator OS loaded in a project and one status line telling you which parts are configured. Nothing else is required to start.

Before you start

You need Claude Code, jq and python3. Check all three:

claude --version
jq --version
python3 --version
What you should see

Three version numbers. If jq says command not found, install it (on a Mac: brew install jq). Without it the plugin still loads, but each hook skips itself and says so.

Step 1. Add the plugin

claude plugin marketplace add ndnstyl/GTM-growth && claude plugin install operator-os@operator-os
What you should see

Two confirmations: the marketplace was added, then operator-os was installed. Run claude plugin list and operator-os is in the list.

Step 2. Open a project and check the status line

Go to any project folder and start Claude Code:

cd ~/my-business-project
claude

Then ask it, in your own words, what the status line says. The status line is handed to the assistant when the session starts, so asking is the reliable check:

What does the operator-os status line say?
What you should see

An answer that starts with operator-os status:. It names each optional part and says ok or not configured, with the one thing to do about it. You can also see it in the session transcript view. When you have a constitution file, a longer STARTUP: block comes first and the status line follows it.

operator-os status: jq=ok python3=ok git=ok | vault: not configured (no folder at ...; run /operator-os:init-vault) | vault remote: not configured (...) | local model lane: not configured (...) | rules: not installed (run /operator-os:install-rules)

That is the design: a missing piece says so once, in plain words, instead of failing later.

Step 3. Install the rules

A plugin cannot ship rule files, so one skill copies them into your project. Type this in the session:

/operator-os:install-rules
What you should see

Eighteen lines beginning copied:, then install-rules: 18 copied, 0 skipped. The files now sit in .claude/rules/ and load on the next session. Run it twice and the second run says 0 copied, 18 skipped: it never overwrites your edits.

Step 4. Confirm

Quit, start Claude Code again, and ask the same question: What does the operator-os status line say? The answer now ends with rules: installed.

If something is off

  • No status line in the answer. Run claude plugin list. If operator-os is missing, repeat step 1.
  • Every hook says "jq not installed". Install jq, restart.

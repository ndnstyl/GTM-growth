Install in one command

Operator OS is a Claude Code plugin. One command adds the agents, skills, hooks and system packs to every project you open.

claude plugin marketplace add ndnstyl/GTM-growth && claude plugin install operator-os@operator-os

You need Claude Code, jq and python3. If jq is missing, each hook skips itself and says so, so nothing breaks; install it to turn the hooks on.

Then set up your project

  1. Install the plugin
    One command. It adds the agents, skills, hooks and system packs. Open a project and one status line says which optional parts are configured.
  2. Install the rules
    Ask for the install-rules skill so the doctrine lives in your project.
  3. Make your vault
    Copy the starter vault, or run the init-vault skill, and set the vault variable.
  4. Read the example
    Open the fictional company's vault and follow one rule from its raw source to its card.
  5. Run the loop
    Build with one seat, check with another, and stop after three rounds.
  6. Add your own hook
    Block a mistake only you know about, and prove it with a test.
  7. Give it a goal
    Run the goal skill with a plain outcome and watch the gates hold.

Optional: the constitution

The plugin ships a short template. Copy it to .specify/memory/constitution.md and fill in who you are. Delete any clause you will not enforce.

Commits and branches

One hook, block-off-trunk-commit.sh, refuses a git commit unless the branch is main or a spec/NNN- worktree branch. If your team works on feature branches, set OPERATOR_TRUNK_BRANCH_RX to a regular expression of the branch names you allow, for example ^(main|feature/.+)$. For a one-time commit on any other branch, set OPERATOR_TRUNK_GRACE=1 for that command or create the file .operator/TRUNK_GRACE; every grace use is logged.

Turn on the gates that ship empty

The platform-write gate, the ingress registry and the api governor each start with no rows. They allow everything until you add your platforms. The platform-write gate guide shows the first row.

Optional hooks

Three hooks ship but are not registered, because each has a cost you should choose. The unslop and name-the-thing gates refuse a final message, which costs a regenerated message. The pre-commit secret scan is a git hook:

ln -s <plugin>/hooks/pre-commit-secret-scan.sh .git/hooks/pre-commit

Check the package

claude plugin validate .
claude plugin validate plugins/operator-os --strict

Hook state and receipts land in your project under .operator/. Add it to .gitignore.

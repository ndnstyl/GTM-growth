# SOP: Weekly Ad Spend Check

**Owner:** Dana · **Cadence:** Fridays, fifteen minutes · **Draft, unsigned**

## Part A: by hand today
1. Open each ad platform's weekly report and note spend for Monday to Sunday.
2. Open the scheduling software's bookings list for the same week, filter to confirmed numbers.
3. Divide spend by bookings per channel, using the definition in [[Cost Per Booked Job by Channel]]. A channel under five bookings reads "too few to read".
4. Write any keyword over the pause line into the list ([[Search Ads Pause Rule]]).

## Part B: what the assistant does today
Ask: "Prepare the Friday ad spend check." It reads the two exports, prints each number with its basis, lists pause candidates, and stages the list for you. It changes nothing in any platform.

## Part C: being built
A saved weekly query so the numbers appear without the exports. Status: building.

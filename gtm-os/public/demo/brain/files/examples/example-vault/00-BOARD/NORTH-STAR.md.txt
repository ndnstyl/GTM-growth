# North star, spring quarter

1. **Every call answered.** A missed call is a lost job. See [[Missed Call Callback Window]] and [[Call Coverage by Hour]].
2. **Spend that proves itself.** No budget goes up until cost per booked job is measured the same way each week. See [[Cost Per Booked Job by Channel]].
3. **Reviews on every finished job.** See [[Review Request Automation]].
4. **A second metro only after 1 to 3 hold for a month.** See [[Second Metro Launch]].

Anything that does not serve one of these four goes to [[QUEUE]] and waits.

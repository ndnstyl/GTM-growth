# Companion skills

Two skills are worth installing but are not bundled, because they belong to their authors and carry their own
licences. Install them straight from the source.

| Skill | What it adds | Install from |
|---|---|---|
| `excalidraw-diagram` | Turns a description into an editable architecture or flow diagram. The visual-design system pack works without it and uses it when present. | https://github.com/coleam00/excalidraw-diagram-skill |
| `remotion` | Best-practice rules for building video in React with Remotion. | https://github.com/remotion-dev/skills |

Operator OS works without either one.

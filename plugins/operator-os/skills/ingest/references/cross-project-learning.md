## Cross-project learning decision


If the source has claims that GENERALIZE across projects (a pattern the operator will
reuse), capture them as `learning_*`/`feedback_*` notes in the main vault
during ingest, indexed in MEMORY.md. If the source is project-specific
(a client SOP, a vendor call transcript), it belongs in the client vault, do not
promote project tactics into the cross-project brain.
